# 지표 정리

| 지표 | 의미 |
| --- | --- |
| 양성 비율 | 예측 대상 시점 중 30분 안에 이상 발생이 있는 시점의 비율이다. 아무 정보 없는 모델의 PR-AUC와 같다 |
| PR-AUC | 정밀도-재현율 곡선 아래 넓이이다. 양성이 드물 때 Accuracy나 ROC-AUC보다 차이가 잘 드러난다 |
| 정밀도(Precision) | 경보를 낸 시점 중 실제로 30분 안에 이상이 시작된 비율이다 |
| 재현율(Recall) | 실제 양성 시점 중 경보를 낸 비율이다 |
| F1 | 정밀도와 재현율의 조화평균이다. 경보 임계값은 Training에서 이 값이 가장 높은 지점으로 정한다 |
| 사건 재현율 | 이상 발생 사건 중 직전 30분 안에 경보가 한 번이라도 울린 비율이다. 시점 단위가 아니라 사건 단위로 센다(Tatbul et al., 2018) |
| 리드 타임 | 사건마다 가장 이른 경보가 이상 발생 몇 분 전이었는지이다. 중앙값으로 보고한다 |
| 하루 오경보 | 이어진 경보 구간 중 30분 안에 이상 발생이 없었던 구간 수를 설비 1대의 정상 운전 하루(1,440분) 기준으로 나눈 값이다 |
| 역률 | 유효전력 / 피상전력. 0.6, 0.8이 SOH 라벨 경계이다 |
| 전류고조파, 전압고조파 | 기본파 대비 고조파 성분 비율(%)이다. 전류고조파는 30/60, 전압고조파는 3/5가 SOH 라벨 경계이다 |
